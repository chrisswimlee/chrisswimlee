Personal site for [chrisswimlee.com](https://chrisswimlee.com) — digital work, resume, and open source.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Pushes to `main` deploy through GitHub Pages (Actions). Set the repo Pages source to **GitHub Actions**.
